# 使用说明

## 一、拿到程序后做什么

分发包有两种形态，选一个即可：

| 形态 | 适用场景 | 注意事项 |
|---|---|---|
| `NetDoctor.exe`（单文件，约 12 MB） | 拷给别人、U 盘随身带 | 首次启动需解压，约慢 2~5 秒；个别杀软可能误报 |
| `NetDoctor/` 文件夹版 | 自己机器上常用 | 启动更快、误报更少，但要整个文件夹一起拷贝 |

**运行需要管理员权限**：程序已内置提权清单，双击时系统会弹「是否允许此应用对你的设备进行更改」，
点「是」即可。若公司策略不允许提权，扫描功能仍可用，但自动修复会失败并提示。

## 二、图形界面操作

### 1. 开始体检

双击 `NetDoctor.exe` → 点左上角 **「开始体检」**。

程序分两步走：

1. **先判定**（几秒）：顶部横幅会亮出结论——**网络健康 / 能连网但上网受限 / 完全断网**，
   右侧写明故障发生在哪一环（如「DNS 域名解析」、「路由器 ↔ 运营商（宽带出口）」）；
2. **后排查**（30~60 秒）：自动继续完整检查 10 大类共 40 余项。

扫描全部是只读操作，不会改动任何设置。

> **两条体验约定**
>
> 1. **不用弹窗**：判定结论、修复结果、回滚结果、报错都直接显示在右侧「详情」区和底部状态条。
>    只有 3 个「确认」框保留（执行修复、进阶二次确认、回滚）——它们拦的是会改动系统的操作。
> 2. **没有真的上网问题就只提示**：健康度**只由实测连通性决定**。探针证明当前能正常上网时，
>    hosts 自定义记录、静态 IP、代理设置、网卡节能这类**可能是你自己设置的**条目，只以「提示」级
>    列出：不计入「需处理」，也不自动勾选任何修复动作。
>    注意条目本身仍会完整展示并给出处理方案，点该行即可查看。

### 2. 看结果

判定结论会显示在右侧详情区，包含**受影响的功能、仍然可用的功能、处理步骤、建议的修复动作**，
网络健康时还会列出「仅为提示」的条目清单。
左侧列表列出**全部**条目，按严重度从高到低排序：

- **级别**：严重 / 高 / 中 / 低 / 提示
- **分类**：A 链路层、B IP 配置、C DNS、D 协议栈、E 代理/VPN、
  F 系统服务、G 路由、H 防火墙、I 系统环境、J 连通性结论
- **可修复**：标「支持」的可以一键修复，标「手动」的只提供操作指引

点任意一行，右侧会显示这个条目的**详细说明、检测证据、处理方案**（点左侧「选」列勾选/取消）。

### 3. 修复

程序会**按本次故障形态**自动勾选相关项目（例如「能上 QQ 打不开网页」只勾选 DNS / 代理类，
不会去动网卡；网络健康时**一项都不勾选**）。你可以：

- 取消勾选不想动的项（点击左侧「选」那一列切换）；
- 勾选列表中标「手动」以外的其它项。

确认后点 **「修复所选问题」**：

1. 弹出确认框，列出将要执行的动作（这是唯一的「确认」类弹窗）；
2. 若含进阶动作（协议栈/防火墙重置），会**二次确认**；
3. 程序先备份配置（hosts、代理设置、IP 配置、路由表、服务启动类型等），
   备份位置会在完成后告诉你；
4. 依次执行修复，底部日志区实时显示每条命令的输出；
5. 自动复测网络连通性，并把顶部横幅刷新为修复后的最新状态；
6. **结果直接显示在详情区**（不弹窗）：动作明细、备份路径、诊断报告路径，
   若仍不通还会按故障形态告诉你下一步该查什么、该找谁。

### 4. 看懂最终结论

| 详情区标题 | 含义 | 你该做什么 |
|---|---|---|
| 修复结果：网络已恢复连通 | 问题已解决 | 若提示"需重启生效"，重启一次即可 |
| 修复结果：仍未连通 +「下一步建议」 | 若已修好全部已知问题 → **本机配置没问题了**，故障在线路/设备/运营商侧 | 先重启光猫与路由器（拔电 30 秒）；仍不行请联系专业人员或宽带运营商 |
| 修复结果：仍未连通 + 动作明细里有失败项 | 自动修复没成功 | 按详情区/报告里的「手动修复指引」操作，或联系专业人员 |


### 5. 撤销（回滚）

如果修复后效果不对，点 **「回滚配置…」**，选择要还原的备份点，
程序会把 hosts、系统代理设置、服务启动类型等还原回当时的状态。

> 只读快照（IP 配置、路由表等）不会自动写回——它们的作用是留档比对，
> 避免"回滚"本身引入新问题。

### 6. 导出报告

点 **「导出报告」** 可以保存为 HTML 或 TXT，用于留档或发给运维/售后。
每次运行也会自动在 `reports/` 下生成一份。

## 三、命令行用法

适合放进批处理、远程协助、工单脚本。

```bat
NetDoctor.exe --quick                      快速体检：秒级判定网络是否正常、断在哪一环
NetDoctor.exe --scan                       扫描并打印结果（只读，零风险）
NetDoctor.exe --scan --fast                快速扫描（跳过 Winsock/防火墙/电源等慢速项）
NetDoctor.exe --fix                        扫描后询问是否修复
NetDoctor.exe --fix --auto                 全自动修复，不询问
NetDoctor.exe --fix --auto --advanced      允许进阶修复（协议栈/防火墙重置）
NetDoctor.exe --json -o result.json        输出 JSON 结果（含 verdict 判定对象）
NetDoctor.exe --quick --json               JSON 形式返回判定结论，便于监控系统采集
NetDoctor.exe --report-dir D:\reports      指定报告目录
NetDoctor.exe --restore                    回滚最近一次修复
NetDoctor.exe --restore 20261016-193000    回滚指定备份
NetDoctor.exe --no-backup --fix --auto     跳过备份（不推荐）
```

常用组合：

```bat
:: 远程协助：先扫描留证，再让用户自己点修复
NetDoctor.exe --scan --report-dir %USERPROFILE%\Desktop

:: 批量运维：静默扫描，结果是 JSON，回去解析
NetDoctor.exe --scan --json -o %TEMP%\nd.json

:: 开机自检：只判定网络是否正常，几秒出结果
NetDoctor.exe --quick --json

:: 无人值守：断电重启后自动跑一遍修复
NetDoctor.exe --fix --auto
```

退出码：

| 码 | 含义 |
|---|---|
| 0 | 成功（扫描完成 / 修复流程走完） |
| 1 | 用户取消 |
| 2 | 指定的备份不存在 |
| 3 | 回滚执行完成但有失败项 |
| 4 | 权限不足，需要管理员 |

## 四、典型场景速查

| 症状 | 先看判定结论 | 常见原因 |
|---|---|---|
| 完全上不了网，网卡显示"未连接" | 完全断网 · 局域网不通 | 网线松了、路由器没电、网卡被禁用 |
| 显示"未识别的网络"、IP 是 169.254.x.x | 完全断网 · 局域网不通 | DHCP 拿不到地址：重启路由器或检查 DHCP 服务 |
| 内网能通，外网不通 | 完全断网 · 外网出口不通 | 路由器 WAN 未拨号成功 / 运营商侧故障 → 联系运营商 |
| 能上 QQ/微信，但浏览器打不开网页 | 能连网但受限 · 域名解析故障 | DNS 解析失败（先刷新/改公共 DNS） |
| 能上 QQ/微信，浏览器打不开，但换个浏览器却正常 | 能连网但受限 · 浏览器路径被代理堵死 | 系统代理指向了已失效的地址 |
| 所有网站提示"连接不安全" / 证书错误 | 能连网但受限 · 系统时间偏差 | 系统时间偏差过大 |
| 小网页能开，视频/下载卡住 | 能连网但受限 · MTU 异常 | MTU 分片黑洞 |
| 特定网站打不开，其它正常 | 能连网但受限 · 域名解析故障 / 完全断网时的 hosts 嫌疑 | hosts 被写入劫持记录（网络正常时此项仅作提示） |
| 挂机一段时间就掉线，动一下鼠标又好了 | 能连网但受限（实测到掉线） / 提示级 | 网卡节能断流（仅当真的掉线时才算故障） |
| 用了 VPN/加速器后彻底断网 | 完全断网 · 局域网/出口不通 | 虚拟网卡残留、默认路由被劫持 |

> 判定结论会直接显示症状属于上表哪一种，并给出对应的处理步骤；不同形态的处理路径不同，
> 不需要全都试一遍。详见 [《体检判定与故障形态》](判定与故障形态.md)。

## 五、目录与文件

程序所在目录下会自动创建：

```
backups/                        配置备份
└── 20261016-193000/
    ├── manifest.json           备份清单（回滚依据）
    ├── files/                  hosts 等文件副本
    ├── json/                   注册表与服务启动类型（结构化）
    └── text/                   ipconfig / route / MTU 等只读快照
reports/                        诊断报告（txt + html）
logs/netdoctor.log              运行日志
```

## 六、常见问题

**Q：扫描时提示"PowerShell 采集不可用，降级为 netsh"？**
A：系统缺少 NetTCPIP 模块（老系统或被精简的系统），程序会自动降级，功能不受影响。

**Q：修复后提示需要重启？**
A：只有进阶动作（重置 Winsock / TCP-IP 协议栈）需要重启。重启后再跑一次 `--scan` 即可确认。

**Q：杀毒软件报警怎么办？**
A：PyInstaller 打包的程序在未签名时可能被启发式误报。建议：
① 优先使用文件夹版；② 把程序目录加入杀软信任；③ 自行用代码签名证书签名。

**Q：会不会把我的设置改坏？**
A：所有修复执行前都会备份；稳健档动作都是可逆的（关代理、刷 DNS、续租 IP、重启网卡等）；
进阶动作默认不勾选，必须二次确认。任何时候都能用「回滚配置…」还原。
而且——**实测能正常上网时，程序一项都不会自动勾选**，你的 hosts、代理等自定义配置不会被顺手改掉。

**Q：hosts 里自己加了很多条记录，为什么没被当成故障？**
A：因为实测证明当前网络是正常的，这些记录目前没造成影响。程序把它归入「提示」级，
不计入「需处理」、也不会自动帮你还原。真正上网出问题时它才会升级为嫌疑项，
届时可以在「dns」形态的预案里一键还原（会先备份原文件）。

**Q：程序会弹窗吗？**
A：不会弹结果类窗口。判定、修复、回滚结果都显示在界面里。仅「执行修复 / 进阶二次确认 /
回滚确认」这三个确认框会出现——因为它们的后续动作会改动系统设置，需要你当下明确同意。

**Q：公司电脑不让提权，还能用吗？**
A：可以扫描（只读），但自动修复会失败。把导出的报告交给 IT 即可。

**Q：程序需要联网吗？**
A：不需要上传任何数据。它只在本机做检测，探针会访问公共 DNS 与常见网站来验证连通性。
